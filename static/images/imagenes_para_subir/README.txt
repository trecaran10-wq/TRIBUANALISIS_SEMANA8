SUBE AQUI LAS IMAGENES PARA PERSONALIZAR TRIBUANALISIS

Puedes copiar tus imagenes a esta carpeta y avisarme cuando esten listas.
No necesitas cambiarles el nombre; dime donde quieres usar cada una:

- Logo para la barra lateral
- Imagen panoramica para el encabezado del inicio
- Avatar o fotografia de perfil
- Iconos u otros recursos del proyecto

Formatos recomendados: PNG, JPG, WEBP o SVG.
Para el encabezado, idealmente usa una imagen horizontal de al menos 1200 x 400 px.
Para logos o avatares, una imagen cuadrada funciona mejor.
